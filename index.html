DEINE DATEN

Backup & Einstellungen

Deine Habits werden automatisch in einer lokalen Datenbank auf diesem Gerät gespeichert. Es wird kein Konto benötigt und deine Daten werden nicht an einen Server übertragen.

Wichtig: Lokale Daten bleiben normalerweise auf diesem Browser und Gerät. Bei Gerätewechsel, Browserdaten-Löschung oder Deinstallation kann ein Backup nötig sein. Exportiere regelmäßig eine Sicherung.
